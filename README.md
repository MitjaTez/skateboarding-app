Skateboarding Slovenija

A full-stack web app for the Slovenian skateboarding community. Discover skateparks and street spots on a map, rate and favorite them, follow events, and read articles.

Tech Stack

Backend
- NestJS
- PostgreSQL with Typeorm
- JWT authentication, bcrypt
- AWS S3 for file storage
- Resend for email
- Jest

Frontend
- React, TypeScript, Vite
- Tailwind CSS 4, Radix UI, Framer Motion, GSAP
- TanStack Query, React Router, React Hook Form + Zod
- Leaflet / Google Maps
- Vitest + Testing Library
